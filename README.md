# Automata

**Automata** é um jogo de programação e resolução de puzzles no qual o jogador controla um robô por meio de uma linguagem de programação inspirada em Java.

O jogador deve analisar cada fase, escrever uma sequência de comandos e observar o robô executá-los no ambiente para alcançar o objetivo proposto.

## Sobre o jogo

As fases são construídas sobre uma grade de blocos contendo o robô, obstáculos, objetivos e elementos interativos.

O jogador não controla o robô diretamente. Em vez disso, ele escreve um programa utilizando os comandos disponibilizados pelo jogo. O programa é então interpretado e executado sequencialmente, fazendo com que o robô interaja com o ambiente.

A linguagem utilizada pelo jogo possui sintaxe inspirada em Java, mas é própria do Automata e limitada às funcionalidades disponíveis no jogo.

A proposta do Automata é transformar conceitos de lógica de programação em desafios de resolução de problemas.

Cada fase apresenta um problema que deve ser solucionado através da elaboração de um programa capaz de controlar o robô e utilizar corretamente os elementos disponíveis no ambiente.

## Funcionalidades

* Sistema de fases baseado em uma grade de blocos
* Controle indireto do robô por meio de código
* Linguagem de programação inspirada em Java
* Movimentação em quatro direções
* Interação com elementos do ambiente
* Detecção de obstáculos e movimentos inválidos
* Execução sequencial dos comandos
* Verificação do objetivo da fase
* Mensagens de erro durante a execução
* Reinício das fases para testar novas soluções
* Interface gráfica para visualização do ambiente e edição do código
